# 차곡

보이차·우롱차·홍차를 기록하는 반응형 정적 웹 시제품입니다.

`dist/index.html`을 브라우저로 열 수 있습니다. 빌드나 서버가 필요하지 않습니다.

- 새 브라우저에서는 빈 달력으로 시작합니다.
- 기존 시제품의 자동 생성 기록·게시글·이벤트를 제거합니다. 사용자가 추가하거나 수정한 차 기록은 보존합니다.
- 기록, 공감, 댓글, 공지는 브라우저에만 저장됩니다. 공개 설정도 현재 브라우저 안에서만 적용됩니다.
- Firebase Google 로그인 코드는 준비되어 있으며 `dist/firebase-config.js`에 프로젝트 설정을 넣어야 활성화됩니다. 실제 관리자 인증과 회원 간 공유는 아직 연결되지 않았습니다.

## Firebase 로그인 설정

1. Firebase Console에서 프로젝트와 웹 앱을 만듭니다.
2. Authentication의 로그인 방법에서 Google을 활성화하고 지원 이메일을 설정합니다.
3. 승인된 도메인에 `leegyuhuen-ux.github.io`를 추가합니다.
4. `dist/firebase-config.js`의 null을 해당 웹 앱의 firebaseConfig 객체로 바꿉니다. 서비스 계정 비공개 키는 넣지 않습니다.
5. 게시 후 실제 구글 계정으로 로그인, 새로고침 후 상태 유지, 로그아웃을 확인합니다.

GitHub Pages에서는 팝업 로그인을 사용합니다. 팝업 차단 시 허용 안내를 표시합니다. 로그인 전 기록과 각 계정의 기록은 별도 브라우저 저장 영역을 사용합니다. 이는 화면과 저장 구분이며, 공유 컴퓨터의 로컬 데이터 암호화나 서버 접근 제어를 제공하지 않습니다. 기존 방문자 기록은 계정에 자동 이전하지 않습니다. Firestore 동기화는 아직 구현하지 않았습니다.

설정이 없는 경우 기존 방문자 기록 기능을 유지합니다. 계정 간 기록 구분은 로컬 검사로 검증했고, 실제 OAuth·모바일 팝업 검증은 프로젝트 설정 후 진행해야 합니다.

## GitHub Pages

저장소의 Settings → Pages → Source를 GitHub Actions로 설정합니다. main 브랜치에 변경을 올리면 포함된 워크플로가 dist 폴더를 배포합니다.

실제 차 기록은 소스 파일에 포함되지 않으며 GitHub로 업로드되지 않습니다. 기존 로컬 파일에서 작성한 기록은 웹 주소로 자동 이전되지 않습니다.
